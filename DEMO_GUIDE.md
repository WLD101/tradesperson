# Customer Demonstration Guide

**Estimated Demo Time:** 10–15 minutes.

## 1. Login (1-2 mins)
1. Navigate to the application entry point (`/`).
2. Demonstrate the modern authentication gateway.
3. Input credentials and execute login.
4. Highlight the multi-tenant branch selection (if applicable for the test user) showing that data is securely isolated by organization context.

## 2. Dashboard (2-3 mins)
1. Arrive at the Workspace Dashboard.
2. Highlight the real-time metrics cards showing active Tenant status, Subscription level, and branch counts.
3. Show the CRM metrics (Leads, Customers, Properties).
4. Direct attention to the **Recent administrative activity** audit log, proving real-time traceability of system events.

## 3. CRM & Customers (3-4 mins)
1. Using the left navigation sidebar, navigate to **CRM > Customers**.
2. Explain the centralized Customer list and data structure.
3. **Action:** Click to add a new customer directly inline on the page.
4. Input details (Display Name, Customer Type, Email, Phone, etc.) and submit.
5. Highlight the immediate visual feedback of the new Customer entry populating seamlessly into the application list.

## 4. Procurement - Purchase Orders (3-4 mins)
1. Navigate to **Procurement > Overview**. 
2. Explain the workflow (Requisitions -> Purchase Orders -> Goods Receipts).
3. Navigate into **Purchase Orders**.
4. **Action:** Initiate a new Purchase Order creation, or open an existing Draft PO to show details.
5. Detail how line items, sub-totals, and authorization status are calculated.

## 5. Procurement - Goods Receipts (2-3 mins)
1. Transition from the Purchase Order to receiving inventory.
2. In the PO Detail view, highlight the integrated **Goods Receipt** module.
3. Explain how Tradesperson uniquely consolidates generic inventory movements purely into Goods Receipts to streamline ERP complexity.
4. Process a mock Goods Receipt against the PO lines to demonstrate inventory intake.

## 6. Logout (1 min)
1. Terminate the demonstration by seamlessly utilizing the Sign Out mechanism.
2. Highlight how the system enforces strict session termination, safely redirecting to the unauthenticated gateway.
