# MVP Acceptance Criteria

The flooring MVP is accepted only when all of the following are true:

1. New tenant registration works.
2. Business setup and branch setup work.
3. User invitations and membership roles work.
4. Permissions are enforced server-side.
5. Leads can be created or imported.
6. Leads convert into customers and properties.
7. Surveys can be booked and completed.
8. Multiple rooms can be measured with stored measurement inputs.
9. Flooring quantities calculate correctly with configurable waste.
10. Products, accessories, and labour can be quoted.
11. Quotes are versioned and historical versions are immutable.
12. Quote PDF generation works.
13. Customer approval and signature are captured.
14. Deposits can be recorded.
15. Accepted quote converts into a job without duplicate entry.
16. Materials can be reserved.
17. Purchase orders can be raised and received.
18. Installers can be scheduled and assigned.
19. Completion checklist and photos can be recorded.
20. Final invoice can be issued and payment recorded.
21. Job profitability is visible to authorized roles.
22. Audit history is available for key operational events.
23. Demo seed data runs successfully.
24. Tenant isolation tests pass.
25. Critical e2e Playwright flow passes.
26. Docker Compose local environment runs successfully.
27. No critical user-facing actions are placeholder-only.
